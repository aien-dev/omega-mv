Write a function collatz_steps_u32(n). The argument n is an unsigned 32-bit integer (u32) with n >= 1 and the result is a u32. Return the number of steps needed to reach 1 under the Collatz rule: if n is even, n becomes n / 2; if n is odd, n becomes 3 * n + 1. collatz_steps_u32(1) = 0. Intermediate values can exceed 32 bits; every tested result is below 1000.
