Write a function reverse_digits_u32(n). The argument n is an unsigned 32-bit integer (u32) and the result is a u32. Return the number formed by reversing the decimal digits of n; for example reverse_digits_u32(1234) = 4321, reverse_digits_u32(100) = 1 and reverse_digits_u32(0) = 0. Every tested result fits in a u32.
