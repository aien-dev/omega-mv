# Offline Omega Trace host tools

This is optional local diagnostic tooling, outside the Omega execution path. It requires Node 24 on Linux (procfs descriptor-relative filesystem access). It has no npm packages, Python, database, server, analytics or transport dependency. It never writes Cortex journals or source receipts. Trace observations carry no proof, authorization, memory or training-control authority. Capture is disabled by default.

`schema.mjs` defines `omega.trace.event.v1`: exact fields, closed numeric metric/unit registry, explicit missing provenance, u64 decimal times/sequences, digest identities/references and capture/privacy classification. No prompt/sample/output/tool-argument/free-text/tensor field exists. Unknown fields and versions refuse. Canonical JSON sorts keys, preserves array order, uses finite numbers and normalizes negative zero. Event identity is SHA-256 over the canonical envelope without event_id. Contract hashes and receipt digests are opaque references, not verification.

`archive.mjs` provides `Archive` (explicit local writer), `BoundedWriter` (optional background host worker with bounded message credits, disabled by default), `readArchive` and `recover`. Producer submissions do no filesystem/network I/O and never throw on validation or queue refusal. This host queue does not replace the native ARGUS SPSC rings. Failed persistence is returned in writer status; callers must retain that status. It cannot veto an engine task. Data loss on crash before a graceful loss flush has unknown extent. No trace buffer holds authoritative evidence.

Each segment begins with the eight bytes `OTRACE1\n`. Every frame is big-endian u32 payload byte length, 32-byte SHA-256 of payload, canonical UTF-8 event bytes. Max record 16 KiB, segment 16 MiB, index 16 MiB. Segments are created exclusively, fsynced, then indexed. The append-only canonical JSONL index records sealed segment size/digest/count and retention/pin operations. The index is an integrity aid, not an authenticated evidence journal. Concurrent writers refuse via an exclusive lock file. Readers work with collection disabled; an active or uncleared writer session makes the snapshot INCONCLUSIVE with unknown queued/crash loss, even when every indexed segment is intact. Packaging requires a subsequent conclusive read after clean close.

A crash may leave an unindexed segment or lock. Reading reports orphan/corruption/missing entries explicitly. `recover` copies every decodable complete frame into a NEW destination and persists source digests, problems and unknown-loss disclosure in recovery.json. It never truncates or repairs the original. No automatic stale-lock removal is attempted. Index exhaustion refuses additional writes. Migration never rewrites a source archive: new versions need a new reader and explicit copy-to-new migration with source hashes and loss disclosures; v1 refuses unknown versions.

Archive root must already have a real existing parent; root is created 0700, files 0600. Set XDG_STATE_HOME or supply an absolute root. Directory components are opened without following symlinks. Reads/writes retain the root inode and verify its identity; unsafe owners/modes, symlinks, traversal, hardlinks and special files refuse. Permissions provide access control, not encryption. Use an exclusively owned directory; malicious concurrent processes running as the same OS owner are outside this boundary.

Retention is explicit: disk budget/age removes only complete unpinned segments, writes durable removal disclosures, then deletes those segments. Pins survive reopen. Purge observes pins and touches only indexed segment files. A tombstoned file still present after an interruption is reported as an INCONCLUSIVE residual deletion. Reads and queries never unlink it or claim erasure; recovery into a new archive preserves the source and the incomplete-coverage disclosure. Successful explicit deletion fsyncs the directory before returning. Unrelated receipts/history stay outside the archive. Retention is not publication revocation or remote erasure.

## Commands

Use `node tools/trace/trace.mjs --root /absolute/private/archive COMMAND`. The root's parent must exist. Export/package/viewer output files require an existing owner-only parent directory, an absolute path outside the source archive, and a new filename. Commands reject unused flags and extra arguments.

- `list`, `stats`: retained runs or typed summaries. Both honor query filters.
- `show RUN`, `steps RUN`, `events RUN`, `verify RUN`: explicit 64-hex run digest. Verify reports archive integrity separately from `evidence: NOT_VERIFIED`.
- `compare RUN_A RUN_B`: visible machine/build/config/precision differences and both qualified query results.
- Query filters: `--session DIGEST`, `--source ENUM`, `--semantic DIGEST`, `--realization DIGEST`, `--step N`, `--type ENUM`, `--status ENUM`, `--range FROM:TO`. Times are canonical u64 decimal and bounds are inclusive. Mixed clock domains with no mapping are inconclusive. Equal timestamps sort by producer, sequence and event digest. Parents remain explicit when filtered out.
- `export RUN --format json|csv [--output ABSOLUTE_NEW_FILE]`: local diagnostic output with source segment digests and the exact query. Units and measurement provenance remain separate. Missing/uncalibrated energy is unavailable. Retention and original known run losses remain visible even if filters hide loss events.
- `share-preview RUN --fields duration,loss [--preset summary|spans]`: exact proposed local contribution bytes. Explicit unique fields required; metric registry plus optional `receipts`. Preview is byte-identical to `share-package RUN --fields ... --output ABSOLUTE_NEW_FILE`. The outer SHA-256 hashes the exact UTF-8 file including its final LF; `content_hash` hashes canonical JSON without content_hash and without final LF. Default is aggregate summary; spans are explicit. In spans, `--fields` selects metrics and optional receipts. Mandatory event metadata is separately listed in `disclosures.privacy_surface.mandatory_span_fields`: hashed event/parent/run/session/semantic/realization identities, producer number, sequence, training step, logical/monotonic time (wall_ns stays null), source/category/status and qualification. The notice warns that these fields disclose workload structure. Review the exact preview before any separately owned consent operation. v1 summary bytes remain compatible; spans gain these additive disclosures and therefore a new content hash. Strict receivers must validate the revised exact bytes. Both remain local candidates with transfer/training permissions false and no consent receipt. Identifiers and contract identities are domain-hashed; wall time is omitted. Unknown schema/metadata/source integrity or unresolved selected parents refuse. Open Humanity independently owns validation, human consent, signing and transport. None is implemented here. Publication does not imply training permission. No remote erasure is claimed.
- `viewer RUN --output ABSOLUTE_NEW_HTML [--other RUN_B]`: self-contained static HTML, bundled CSS/script, browser CSP denies connections, no server/listener, no browser launched. Filters and training-step charts use typed values; unknown measurements, synthetic/estimated qualifications and loss remain visible. Raw prompt/sample fields do not exist. CLI fallback is always available.
- `pin --name 00000001.seg --pinned true|false`; `retain --bytes N [--age-ms N]`; `purge`: explicit owner control. Complete pinned segments remain. Retention tombstones preserve known loss-event summaries, including counts, after deleting data segments. The index has a finite 16 MiB quota; exhaustion refuses the operation before deleting the segment.
- `recover --destination ABSOLUTE_NEW_ARCHIVE`: copies all complete decodable frames, including orphan segments, into a new directory and records uncertainty; original bytes remain untouched. Stale locks are not removed automatically.

## Existing producer adapters and boundaries

`import-searchtrace`, `import-argus`, `import-dual` require `--input-root ABSOLUTE_PRIVATE_DIR --input SIMPLE_FILENAME --context SIMPLE_FILENAME`. The context file is a valid v1 event providing the owner's run/session/build/privacy contract, not a model prompt. The command imports only validated typed observations, never source free text. Input files remain unchanged; writes go only to the separately selected archive.

SearchTrace additionally requires `--verifier ABSOLUTE_BINARY --verifier-hash SHA256`, using the existing `searchtrace verify` implementation. The binary is opened without following a symlink, checked against the exact hash and owner/write permissions, and executed through an inherited descriptor. Its input is an unlinked private descriptor, and no subprocess-output socket pairs are needed. Candidate and realization observations keep causal links, existing program/machine IDs and estimated `rcycles`. The legacy corpus provides no stable realization ID, so that field stays null. It generates differential realizations inside its existing recorder; this batch does not attach that recorder to production or re-run a production effect.

ARGUS consumes the existing 128-byte ABI v1.1 stream, keeping stream sequence/tick and digest references; malformed versions/classes/sequence replay/truncation refuse. It copies authority outcomes without any re-authorization and preserves critical-loss counts. DUAL consumes the existing canonical recommendation kind 5/version 1; retains the actual versus advisory choice, predicted cost, uncertainty, measured outcome and recommendation digest. Unknown/missing calibration remains uncalibrated; optional `--calibration-state stale|refused|unknown` preserves a qualified refusal. Trace cannot grant FRESH status. No recommendation can authorize production.

`BoundedWriter` is scoped to one run/session. Initialization synchronously acquires and fsyncs a session marker before submissions can be accepted, then hands it to the worker. Producer submit remains free of filesystem I/O. The worker owns append I/O; queue credits and retained diagnostic-error strings are bounded. Graceful loss records retain producer and lost source/category codes (the source/category enums are their zero-based registries). At most 4096 distinct attribution keys are retained plus one explicit overflow attribution key (producer 65535, source trace, category loss). Submitted/persisted counts and error counts are returned separately. Callers must inspect status, because accepted into the queue is not a durability promise. Invalid input and cross-run/session mixing refuse diagnostically and cannot veto an engine task. Abrupt death before a loss flush leaves unknown loss extent.

## Native integration gate

The installed native SearchTrace interface is `void (*)(void *, const StEvent *)`, with thread-local installation and nested realization behavior (`src/searchtrace/st_hook.h`). Existing OSC compiled functions require `OscRt *` in x7 and byte slices use pointer/length pairs (`src/compiler/osc_rt.h`, `docs/osc/OSC-EXT-BYTES-DESIGN.md`). No qualified foreign callback bridge between those ABIs was found at this base. The separate `osc/syscall` branch adds syscalls, not a callback bridge. Adding such a bridge or C callback implementation to the execution path exceeds this batch's language/live-engine boundary. Native callback attachment, thread-exit/nesting/full-native-ring equivalence and representative CPU/GB10 overhead remain NOT_RUN. The implemented observers are read-only host import adapters, not a claimed in-process integration.

## Verification and delivery

`tests/trace/run.sh` and optional `make test-trace` exercise host regressions, existing hookcheck, independent native encoder fixtures and a kernel-enforced no-network workflow. Viewer interaction tests execute the bundled script with an in-memory DOM fixture, not a real browser. `tests/trace/mutants.mjs` requires actual behavioral assertion failures. See `docs/trace/L489-ACCEPTANCE.md` and `evidence/L489/README.md` for exact commands, counts, hashes and remaining gates. Hardware, energy, timing/footprint, live training, cross-project signing/transport and independent review are NOT_RUN. No issue closure is claimed.

Arithmetic overflow in a dropped-event counter records an explicit unknown/null count and status flag rather than wrapping. The viewer preserves unknown counts as unknown. Recovery never resurrects segments with durable retention tombstones; retained known loss summaries are copied with persistent incomplete-coverage qualification.
