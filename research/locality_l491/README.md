## Executable scope

`locality.om` has three bounded request types. Requests are decimal uint64 words separated by ASCII whitespace on stdin. EOF terminates a request. Extra words, malformed numbers and overflow refuse. Successful output is one decimal word per line. Each invocation is isolated and has fixed pools, no heap, no files and no sockets.

1. Legal schedule replay: `1 N capacity_B event_count output_mask`, followed by N triples `(size_B, predecessor_mask, flags)`, then event pairs `(kind, node)`. N is 1..16; sizes 1..1048576; at most 64 events. IDs must be topologically ordered. Flag 1 means an input initially in slow storage, 2 means a pure recomputable node, 4 means a required final persistent value. Event 0 loads, 1 computes, 2 stores, 3 drops. All predecessors must be in fast storage; input and output coexist during a computation. Repeated computation of an impure node refuses. All outputs and persistent values must end in slow storage. The result is `(transfer_B, peak_fast_B, compute_count, load_count, store_count)`. This is a dependency/placement validator, not a cost optimizer. Aliases/in-place operations are outside this bounded model.
2. Exact assumption comparison: `2`, thirteen expected IDs, thirteen current IDs. Returns 1 only when every nonzero ID matches; otherwise 0 (use incumbent). IDs are externally interned exact identities, never truncated hashes or similarity scores. The ordered fields are model/weights, shape, dtype, layout, hardware, build, numerical contract, capacity/pressure envelope, input, preprocessing, stochastic state, optimizer/training method, qualification/evidence. The caller must establish collision-free IDs from full validated identities. This host comparison is not #522 admission authority, a cache, or permission to execute an unknown candidate. Dynamic activations are not compiler constants; exact output reuse additionally requires the input/state identities.
3. Recurrence: `3 N depth arm capacity_B cancel_before_iteration contract`, then N weights and N initial states. N/depth 1..64; contract 1 is unsigned modulo 2^64. The recurrence is `h[t+1,i] = h[t,i]*(w[i]+3)+(i+1)`. Arms: 0 streaming reference; 1 prepare pure `p=w+3`, then stream; 2 retain prepared p and state; 3 retain weights/state and recompute p; 4 retain state, store/reload p. Independent lanes permit loop interchange in retained arms; no recurrence dependency is permuted. Locals retain state through the inner loop in native host code. Outputs are analytical logical transfer bytes, pure additions, recurrence updates, declared fast working-set bytes, then final states. These byte counts describe the declared schedule boundary, not observed host or GPU memory transactions. Global input/output pools and compiler call frames remain host memory and are not chip SRAM evidence.

Exit codes: 20 malformed/unsupported, 21 missing predecessor, 22 capacity, 23 invalid storage/impure replay, 24 missing final output, 25 cancelled, 26 short write. Refusals produce no success record. There is no unbounded persistent worker or lease service.

`oracle.c` independently replays sets and exhaustively searches every placement of a five-node diamond. For two 8-byte inputs, two pure nodes using both inputs, and an output using both pure nodes, minimum traffic is 24 B at capacity 32 B, 40 B at capacity 24 B, and infeasible at capacity 16 B. These are exact two-level bounds for this tiny DAG only. The supplied legal schedules attain both bounds. Distributed registers, shared memory, caches, banks and cross-SM communication are not represented by a chip-wide pooled capacity. Real-model lower bound remains UNKNOWN.

## Training capability audit, issue 606

At the pinned base the tape dispatches to M20 CPU F32 only. Working backward primitives: add/sub/mul/div/max/sqrt/matmul/transpose/broadcast/sum/mean, with broadcast reduction and gradient flattening. Forward tensor existence does not imply GPU backward support. M22 supports plain SGD and optional heavy-ball momentum plus transactional generations and dispatch records. Adam/AdamW, Muon, transformer GPU backward, an end-to-end fine-tuning loop and LoRA are not established by these sources. Existing `train/tgemm-cut1` and `train/encoder-r5` remain proposed dependencies, not complete training support. No LoRA equivalence claim.

The uncovered integration fixture uses two F32 parameters, input `[1.25,-0.75]`, target `[0.5,-0.25]`, independent masks in `{0,2}`, squared-error sum, plain SGD lr=1/32 and no momentum. A caller-managed LCG provides masks; this tests multiplication by an explicit stochastic mask, not an implemented dropout operator. Numerical probes use seed 491 over 24 states; repeated checkpoint steps use initial parameters `[0.25,0.5]`, RNG seed 123456 and configuration tag 491 for 12 updates. Retained and rebuilt tapes use the same saved RNG state. The next RNG state and configuration tag are stored in M22 optimizer bytes with a fixture dispatch record; checkpoint resume is compared to uninterrupted execution after steps 4 and 8.

Independent double calculus and central differences check derivatives; frozen gradient relative error is 1e-3, with exact zero handling. Schedule losses/gradients and scalar F32 boundary-by-boundary SGD updates are bit-identical. Computing the whole derivative once in double is not the F32 contract, so the independent update oracle explicitly rounds each forward/backward arithmetic boundary. No tolerance was raised. Transaction snapshots and stochastic state also match bit-for-bit; stale shadow commits refuse.

Known logical training payloads: weights 8 B, final parameter gradients 8 B, stochastic checkpoint state 8 B, input/mask/target 8 B each, four 8 B forward intermediates plus 4 B scalar loss. Tape descriptors, intermediate gradient storage, temporary reduction buffers, shadow/committed snapshots, files, accumulation/communication and peak allocator memory are not measured. These are separate lifetimes; no claim that their sum is a peak. The full training ledger and any sustained campaign remain with training owners.

Tests never qualify learning quality. Model/data splits, quality target, convergence, performance, energy and selection regret remain NOT_RUN. There is no production candidate admission or training campaign.
