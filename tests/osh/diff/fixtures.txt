# OSH cross-adapter stage/stream fixtures (omega#568, parent aien-architecture-mv#158). Format: README.md in this directory.
# Implementation-agnostic: every fixture names toy operations (README, "Toy operations"), never a host path, so the request
# record the shell core builds is the same bytes on every adapter. Expected values were written by hand from
# OSH_PLATFORM_ABI.md v1 DRAFT (sections 5, 7, 8, 10, 12) and the toy contract; stream checksums are FNV-1a 32 computed by
# separate code, not by the runner. scope portable = every adapter must agree; scope linux = Linux-only mechanism
# (rlimits, stop signals, EMFILE), host column only, native reports NOT_RUN.
abi aien-protocols-mv@fb5fca98e6676bb104888c73268e0f9a81e9c63e specs/osh-platform/OSH_PLATFORM_ABI.md v1-draft

fixture f01_two_stage
scope portable
covers two-stage pipeline; producer shutdown: EOF reaches the consumer when the only writer exits

err P0=OK
end
