# Seed-native SHA-256 command and migration receipts — L550

`seed/native/sha256.om` hashes stdin and emits exactly 64 lowercase hexadecimal digits plus LF. The stream adapter was handwritten in Omega. The SHA implementation is existing native Omega reused byte-for-byte from `seed/retirement/trn1/trn1.om` at `12251e3403d42931ada27dc1c54b3b610954be5d`; it was not translated from C or rewritten as a duplicate implementation. Exact ranges, original hash and imported-range hashes are in `sha256-provenance.json`. Original NOTICE and AGPL licence are retained as `seed/native/SHA256-NOTICE` and `SHA256-LICENSE`.

## Contract

Linux AArch64 stdin/stdout, no argv/file-path API. Fixed 8192-byte input block and bounded SHA workspace. At most 8 MiB input; exit 0 success, 2 read/write failure, 3 input exceeds capacity. No digest is emitted before EOF. Read failures are fail-closed, including EINTR; partial reads and writes are handled. Linux signal dispositions are inherited, so SIGPIPE may terminate a closed-output-pipe process before write can report failure. No timing or constant-time security claim is made.

The retained `sha256-main.om` is the handwritten adapter source; `import-native-sha256.py` assembles exact native-source sections from the pinned Git object, verifies byte equality and preserves licences. This script is host tooling, not a translator and not a runtime dependency. `sha256.om` is complete and can be compiled directly without that script or the original repository.

## Real integration, and trust boundary

`native-closure.sh` builds this command with the unchanged qualified compiler, validates its ELF with the Omega checker, and uses the command to produce fingerprints for seven native binaries and four Omega sources. `hash-receipts.py` independently verifies all eleven against hashlib.

The initial host `sha256sum` check of the compiler remains. Removing that independent check and claiming trust based on a hash program compiled by the compiler under examination would be circular. The native hasher cross-checks the same compiler pin afterward; it is not its own trust anchor. Early seed reconstruction, file handling and test supervision still use host utilities. The source/seed/runtime boundaries stay distinct.
