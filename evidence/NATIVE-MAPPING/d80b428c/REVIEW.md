# Bounded desk review disposition

The existing desk independently read the functional delta and replayed the full
host qualification before publishing draft PR676. This is a bounded review, not
final-source or hardware acceptance. The original report remains in the local
L788 handoff; the review raised five observations.

1. Generation exhaustion is enforced by the existing code. A vacant slot is
   reusable only when its generation is strictly below `2^55 - 1`. Allocation
   increments that value once; after the maximum generation is closed, the
   slot is skipped permanently. If all slots are retired/occupied, allocation
   returns -24. A separate trap is not needed. The new white-box `genlimit.om`
   test reduces only that compiler literal to3, executes all384 generations,
   verifies every exact handle, and observes final exhaustion. This exercises
   the same retirement branch; it is not a claim of physically iterating 2^55
   times or changing the production ceiling.
2. `mapping.om` now explicitly holds five distinct caller values across
   mapwrite, mapread and mapdrop and checks all five after each operation. The
   complete host gate passes with this stronger test.
3. The existing slots mutant changes the emitted limit from128 to127, so it
   does target the capacity boundary. The unchanged test requests all128 slots
   then expects the129th request to refuse. Two additional compiled controls
   now remove access-value and mode-value validation independently. The native
   compiler-refusal driver rejects both, with exits7 and8 respectively. Its
   original16 cases also cover nonliteral access/mode arguments.
4. The shipped compiler binary is regenerated by the existing seed bootstrap:
   `sh seed/omega-from-seed.sh`. Full qualification wraps it in
   `quiet-build sh seed/host/check.sh`. The receipt records byte-identical first,
   second and third stages from the clean exact-source export. The70 original
   fixtures establish compatibility in addition to that reconstruction proof.
5. These remain process-local handles, with ordinary Linux fork behavior. They
   are not a sandbox or authority mechanism. The contract and PR body retain
   that boundary.

No production compiler change was required by these observations. The original
compiler hash and receipt remain valid. New test-source hashes and actual control
results are recorded in review-controls.json. Independent final-source review and
the native GPU/model integration gates remain open.

Three explanatory statements in the original desk report also need correction:
slot128 is valid (the emitted condition rejects values greater than128, and zero);
mapdrop retains the generation and allocation advances it; and mapwrite accepts
read-only input arrays while mapread requires a writable destination. The actual
source and tests establish these behaviors. The original review is preserved.
