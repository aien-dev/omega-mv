# om/reuse: REUSE-1 candidate units (omega-mv #742 #743 #744)

Contract: `docs/reuse/REUSE-1.md` v1.0 (frozen at d6edaad1) and its clarifications
`docs/reuse/REUSE-1-CLARIFICATIONS.md` (K1..). Every file is handwritten seeded Omegese compiled by
the pinned omc (sha256 `734f0a39319fbfa930bcc62cb30dbf06d47d78e126372b74f5baf478e6126b61`).

## Files

| file | role | prefix |
|---|---|---|
| `om/sha256/sha256.om` | SHA-256 (`omsha`), main, unchanged | |
| `r1.om` | profile R1 baseline: programs, lane map, folds, delta, digests | r1 / R1 |
| `exp.om` | experience records: tap writer, ALLOW, admission | ex / EX |
| `check.om` | G3 bind validation (`ckbind`) | ck / CK |
| `delta.om` | incremental execution | dl / DL |
| `select.om` | lifecycle-cost selector | sl / SL |
| `lib.om` | manifest, CURRENT, publish (drive), `lbload` / `lblineage` / `lbcalpath` (router) | lb / LB |
| methods.om | generated by `codegen.om`, never stored in the tree | mt |
| `router.om` | the arm process (`fn main`) | rt / RT |
| `learn.om` | template admission (drive only) | lg / LG |
| `codegen.om` | methods.om source text (drive only) | cg / CG |
| `drive.om` | the build CLI (`note units: sha256 r1 exp lib learn codegen`) | dr / DR |

A router is the concatenation, in this order: sha256, r1, exp, check, delta, select, lib, methods,
router (a newline is added after a unit that lacks one).

## Build and run (cwd = the omega-mv repo root)

```sh
OMC=$HOME/.local/state/reuse/bin/omc            # check: sha256sum = 734f0a39...6b61
nice -n 19 $OMC < tests/reuse/run.om > /tmp/run.elf && chmod +x /tmp/run.elf
/tmp/run.elf compose $OMC om/reuse/drive.om /tmp/drive.elf    # drive by its units line
/tmp/drive.elf base $OMC OUTDIR                  # OUTDIR/base.om, OUTDIR/base.elf
/tmp/drive.elf build $OMC ALLOW CALIB OUTLIB [unit:NAME=PATH]... [mutant:c1|c1b|c1c]... [crashafter:K] EXP...
/tmp/drive.elf selftest
/tmp/run.elf $OMC                                # every tests/reuse/*.om
/tmp/run.elf $OMC lib-load                       # one test
```

`drive base` prints `base_elf_sha256=<hex>`. `drive build` prints `manifest_sha256=<hex>`,
`generation=<G>`, `templates=<K>`; `<hex>` is the MANSHA the evaluator passes to the router
(`ARM LIBDIR MANSHA ALLOW TAPFILE SPLIT`).

### drive build inputs

- `OMC`: the compiler, forked with stdin = gen-G.om.tmp and stdout = gen-G.elf.tmp (`dupfd`),
  stderr inherited; killed after 120 s. Its file SHA-256 goes into manifest words 14..17 (lbload
  refuses anything but the pinned omc).
- `ALLOW`: `<64 hex> AUTHORIZED|SYNTHETIC|REVOKED <label>` lines (exp.om); read only when EXP files
  are given.
- `CALIB`: `-`, or a 1600-byte R1CAL001 file (magic, version 1, words 3..7 zero, K4); copied to
  `gen-G.cal` (K1), its SHA-256 in manifest words 52..55.
- `OUTLIB`: created 0700 when missing. G = (G named by CURRENT) + 1, or 1 without CURRENT.
- `EXP...`: 0..8 experience files, each admitted by `exadmit` (any refusal: exit 10). Zero files
  give the empty library (K = 0).
- `unit:NAME=PATH` replaces one handwritten unit (sha256 r1 exp check delta select lib router;
  not methods), for control mutants. `mutant:` changes codegen only (K10): `c1` mtfind compares AGG
  shape ids with the wl byte cleared; `c1b` every wl-16 mtl ends with `v = and v 255`; `c1c` mtl
  reads c_j from R1P word 5 + 2j. `crashafter:K` (K 1..9, control C8) stops after publish step K.

### Template admission (5.3, K3)

Only TRAIN records (word 9 = 1) are counted; every record is one QUERY; outcome words (5, 6, 7)
are never read. The FSM template is decided first: admitted iff at least 8 FSM TRAIN records. AGG
shapes (r1shape of the record's PROG) are admitted in descending count, ties to the lower shape id,
while count >= 8 and K < 16 (so at most 15 AGG when FSM is admitted). Library order: AGG in
admission order, then FSM. Lineage digests (file SHA-256s) are sorted ascending; a duplicate file
or more than 8 files is exit 2.

### Generated methods (3.2, 12)

Per AGG template t: `mtl<t> x` applies the ops in order with c_j = R1P word 4 + 2j (ADD, SUB, MUL,
SHL masked to 2^wl - 1), and `mtr<t>` is the fixed loop `acc = r1ident f; acc = r1fold f acc
(mtl<t> x_i)`. FSM: `mtr<t>` walks R1T[16 q + a] (filled by ckbind with r1delta) and sums
λ = R1P word 6 + q. Then `mtcount`, `mtshape`, `mtfind` (r1valid, then r1shape equality; -1
otherwise or for an empty library), `mtlane`, `mtrun` (unknown t: r1full), `mtsrc` (SHA-256 of the
template's functions text, embedded as constants). The text depends only on the template list and
the mutant bits.

## Library files (3.4, K1, K3)

LIBDIR (0700): `gen-G.om`, `gen-G.elf`, `gen-G.cal` (only with CALIB), `gen-G.man`, `CURRENT`.

- Manifest: 256 little-endian words: 0 magic 3544386019401740626, 1 version 1, 2 G, 3 parent G,
  4 K, 5 router source bytes, 6..9 source SHA-256, 10..13 ELF SHA-256, 14..17 compiler SHA-256,
  18 profile version 1, 19 L, 20..51 lineage, 52..55 calibration SHA-256 (0 without), 56..183
  templates (shape id, family, wl, f, k, TRAIN QUERY count, bytes of its generated functions, 0;
  FSM: 1, 2, 0, 0, 0, count, bytes, 0), 184..254 zero, 255 FNV-1a 64 (basis
  14695981039346656037, prime 1099511628211) over the 2040 LE bytes of words 0..254.
  Digests: word j = digest bytes 8j..8j+7 big endian.
- CURRENT: 40 bytes, G (u64 LE) then the 32 SHA-256 bytes of gen-G.man.
- Publish (lbpub, ADR 0015 order), with the steps `crashafter:K` stops after:
  1 gen-G.om.tmp fsync, renamed (renames flag 1: never replaces) to gen-G.om;
  2 the same for gen-G.elf; 3 the same for gen-G.cal (no-op without CALIB);
  4 gen-G.man.tmp written and fsync'd; 5 renamed to gen-G.man; 6 LIBDIR fsync;
  7 CURRENT.tmp written and fsync'd; 8 renamed onto CURRENT; 9 LIBDIR fsync.
  After K <= 7 CURRENT still names the previous generation; after K >= 8 it names G. The next
  build removes the unpublished leftovers of generation (CURRENT G) + 1 and CURRENT.tmp first.
- Determinism (3.5): the same inputs and the same OUTLIB state give byte-identical gen-G.om,
  gen-G.elf, gen-G.cal and gen-G.man (no time, pid or path in any of them).

## Load (router side, lib.om)

`lbload` (B started with ARM method/delta/select, LIBDIR not `-`, argc 7) reads argv itself, and
returns only on refusal; on success it execs `/proc/self/fd/N` (a memfd holding gen-G.elf) with
the same arguments plus `loaded`. Refusal codes:

| code | check | code | check |
|---|---|---|---|
| 1 | argv count / LIBDIR length | 14 | profile version |
| 2 | MANSHA not 64 hex digits | 15 | K > 16 or L > 8 |
| 3 | CURRENT unreadable | 16 | a reserved manifest word nonzero |
| 4 | CURRENT not 40 bytes | 17 | ALLOW unreadable (only when L > 0) |
| 5 | gen-G.man unreadable | 18 | a lineage digest not allowed (absent or REVOKED) |
| 6 | gen-G.man not 2048 bytes | 19 | gen-G.cal unreadable |
| 7 | SHA-256(gen-G.man) differs from CURRENT | 20 | gen-G.cal digest |
| 8 | CURRENT digest differs from MANSHA | 21 | gen-G.elf unreadable |
| 9 | magic | 22 | memfd failed |
| 10 | version | 23 | copy into the memfd failed |
| 11 | self-check | 24 | ELF digest |
| 12 | G differs from CURRENT, or parent G >= G | 25 | exec failed |
| 13 | compiler SHA-256 not the pinned omc | | |

`lblineage` (same checks 1..16, no ELF) fills LBLD, LBLN, LBGEN, LBCAL for the revocation checks
of a loaded generation; `lbcalpath` writes `LIBDIR/gen-G.cal` and a 0 byte into LBCP.

## drive exit codes

0 ok, 2 usage (including a malformed CALIB, an unknown mutant, an unreadable unit, a duplicate or
ninth EXP), 10 experience refused (ALLOW unreadable or an EXP not admitted), 11 compile failed (omc
nonzero), 12 publish failed (including an unreadable existing CURRENT), 13 budget exceeded (omc over
120 s, router source over 512 KiB, LIBDIR over 8 MiB, shape table full), 97 deliberate stop after
publish step K. A refused build removes its tmp files and leaves CURRENT unchanged.

## Tests (`tests/reuse/`, runner `run.om`)

The first line of each test is `note units: ...`; `run.om` composes the units and the test,
compiles with OMC, runs it with argv 1 = a fresh temp dir, argv 2 = OMC, argv 3 = a drive ELF it
built from `om/reuse/drive.om`, 120 s each, and prints one PASS/FAIL line per test and a summary
(exit 0 iff all passed). Work files: `/tmp/reuse-test-run-PID/` (left for inspection).

| test | covers |
|---|---|
| lib-load | every lbload refusal 1..21, 24 as a mutant of a good library, C6 coherent replacement, lblineage, lbcalpath |
| lib-publish | FNV-1a known answer (computed outside Omega), manifest round trip, CURRENT layout, no replacement, lbpub steps 1..9 |
| learn-select | 5.3 / K3 on experience files admitted by exp.om |
| codegen-run | generated methods compiled and compared with r1full / r1lane on random programs; c1, c1b, c1c caught; empty library |
| drive-publish | drive build output, manifest fields, determinism, load, crashafter 1..9, every drive refusal |
| drive-smoke | built routers on the arm protocol: method, delta, select, full, wrong MANSHA, c1c refused by G3, drive base |

Not tested: the 120 s omc budget (a test would take 120 s), and lbload codes 22, 23, 25 (memfd,
copy and exec failures cannot be provoked without changing the host).
